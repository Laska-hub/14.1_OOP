# 14.1_OOP — Управление категориями и товарами

Проект демонстрирует работу с объектно-ориентированным программированием в Python.  
Реализованы классы `Product` и `Category`, поддержка загрузки данных из JSON и тестирование через `pytest`.

## 📁 Структура проекта

14.1_OOP/
│
├── products.json # Файл с данными товаров и категорий
├── src/
│ └── main.py # Основной код проекта
├── tests/
│ └── test_main.py # Тесты с pytest
├── pyproject.toml # Конфигурация Poetry и зависимостей
├── poetry.lock # Зафиксированные версии пакетов
└── README.md # Этот файл

## ⚙️ Установка и настройка

1. Клонируем проект:

```bash
git clone <URL_репозитория>
cd 14.1_OOP

Устанавливаем зависимости и создаём виртуальное окружение через Poetry:

poetry install
poetry shell

Убедитесь, что Python 3.13 активен:

python --version

▶Запуск проекта

Внутри виртуального окружения:

python src/main.py

Запуск тестов
poetry run pytest
